# 部署与账号说明

## 账号体系

### 内置账号

- 教师/管理员：`teacher` / `teacher123`
- 演示学生：`student` / `student123`

### 公开注册规则

- 注册学生：必须填写自己的 AI API Key
- 注册教师：必须填写教师授权码
- 教师授权码由服务器环境变量 `TEACHER_REGISTER_CODE` 控制
- 开发环境默认授权码：`teacher2026`
- 生产环境必须在 `.env` 中改成自己的授权码

### AI Key 和练习数据

- AI Key 加密保存到学生账号下，跟随账号走
- 换电脑登录同一个账号，Key 不需要重新配置
- 提交记录、判题结果、AI 反馈、学习统计都保存在 MySQL，跨设备可见
- 编辑器草稿会自动保存，登录后进入题目可恢复上次未提交代码；点击“运行/提交”会额外保存提交记录

## Ubuntu 24.04 部署

### 1. 传输项目

Windows PowerShell：

```powershell
scp -r "D:\振涛教育\学生考试\理论判卷神器\coding-platform" ubuntu@服务器IP:~/coding-platform
```

### 2. 安装 Docker

```bash
cd ~/coding-platform
bash deploy/ubuntu/setup_ubuntu.sh
newgrp docker
```

### 3. 配置环境变量

```bash
cp deploy/ubuntu/.env.production.example .env
nano .env
```

必须修改：

- `MYSQL_ROOT_PASSWORD`
- `DATABASE_URL`
- `SECRET_KEY`
- `TEACHER_REGISTER_CODE`

生产环境建议保持：

```bash
EXECUTION_MODE=docker
PYTHON_RUNNER_IMAGE=python:3.12-slim
CPP_RUNNER_IMAGE=gcc:13-bookworm
```

### 4. 启动

```bash
cd ~/coding-platform
bash deploy/ubuntu/deploy.sh
docker compose ps
```

### 5. 更新代码

Windows PowerShell：

```powershell
scp -r backend\app ubuntu@服务器IP:~/coding-platform/backend/
scp -r frontend\src ubuntu@服务器IP:~/coding-platform/frontend/
```

Ubuntu：

```bash
cd ~/coding-platform
docker compose up -d --build backend frontend
docker compose ps
```

### 6. 常用运维

```bash
docker compose logs -f backend
docker compose logs -f frontend
docker compose down
docker compose up -d
```

## 常见问题

### 后端 502

```bash
docker compose ps
docker compose logs --tail=80 backend
```

### Docker 沙箱无法执行代码

```bash
docker pull python:3.12-slim
docker pull gcc:13-bookworm
docker compose up -d backend
docker compose logs --tail=80 backend
```

### 缺少 cryptography

```bash
docker compose build --no-cache backend
docker compose up -d backend
```

```bash
echo '{"registry-mirrors":["https://docker.m.daocloud.io","https://docker.1ms.run","https://docker.xuanyuan.me"]}' | sudo tee /etc/docker/daemon.json
sudo systemctl restart docker
```
